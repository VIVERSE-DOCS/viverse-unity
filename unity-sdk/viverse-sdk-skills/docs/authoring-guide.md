# Authoring Guide

Author skills in `skills/<skill-id>/` with:
- `SKILL.md` — entrypoint with YAML frontmatter (name, description, prerequisites, tags)
- `skill.json` — machine-readable metadata (id, version, status, read_order, dependencies)
- `patterns/` — reusable code patterns
- `examples/` — optional reference implementations
- `rules.json` — optional compliance rules (regex + severity)

See the repository-root `AiSkillGuildLine.md` for the full authoring template.
